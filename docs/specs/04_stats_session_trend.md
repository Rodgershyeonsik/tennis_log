## 1. 범위

**구현할 것**

- 03에서 "준비 중" 안내만 둔 **태그 통계 탭**의 내용
  - 기간 표시
  - 세션별 평가 추이 카드: 차트 태그 드롭다운, 세션별 누적 막대 차트(좌우 스크롤), 선택한 세션 줄
  - 같이 달린 태그(차트 태그를 골랐을 때)와 전체 메모에 달린 태그(`태그 전체`일 때), 메모 시트
  - 페이지 평가·태그 필터에 대한 임시 안내
- 03 위젯 수정 두 가지(이 문서가 수정을 허가한다)
  - 세션 상세 시트: 고른 메모 없이 여는 모드
  - 메모 카드: 오른쪽 화살표를 숨기는 옵션
- 통계 집계 로직(순수 Dart) + 단위 테스트

**구현하지 않을 것**

- 필터 재구성(진입 버튼을 세션 필터 / 태그·평가 필터로 나누고 필터 시트를 다시 짜는 일). 별도 명세로 한다. 그때까지는 4번의 임시 안내로 버틴다.
- 비중(100% 누적) 보기, 요약 카드, 태그별 변화 목록. 04를 실제 데이터로 써 본 뒤 다시 판단한다.
- 차트 패키지. 막대 차트는 위젯(또는 `CustomPaint`)으로 직접 그린다. 새 패키지는 추가하지 않는다.
- 통계 탭에서의 모든 편집. 읽기 전용이다.

### 이 기능으로 할 수 있어야 하는 조회 (점검 기준)

1. 범위 1개월 + 세션 유형 게임으로 걸고, 차트 태그를 `#포핸드`로 골라 세션마다 포핸드 메모가 몇 건이고 평가가 어떻게 나뉘는지, 시간에 따라 어떻게 바뀌는지 본다. 포핸드 메모가 없던 게임도 0으로 보인다.
2. 특정 세션 막대를 눌러 그 세션의 평가별 건수를 확인하고, 세션 상세 시트를 열어 그 세션의 메모 전체를 본다.
3. `#포핸드` 메모에 같이 달린 태그를 카테고리별로 보고, 그중 `짧은공` 칩을 눌러 두 태그가 함께 달린 메모를 본다.
4. 차트 태그를 `태그 전체`로 두고 세션별 전체 메모의 평가 추이를 본다.
5. `태그 전체`에서 기간 동안 어떤 기술·폼·상황 태그를 가장 많이 적었는지 보고, 정렬을 `못함 순`으로 바꿔 못함이 많은 태그를 본다.

## 2. 데이터 범위

통계 탭은 **세션 조건은 메모 탭과 공유하고, 메모 조건은 따로 둔다.**

### 조회 대상

03의 3번과 같다. status = complete이고 tagReviewed = true인 세션, confirmed 태그와 confirmed 평가만 쓴다. 결과 탭 위의 "확인 완료 전 일지 N개는 빠졌어요" 안내도 그대로다.

### 1차: 세션 (메모 탭과 공유)

- 조회 대상 세션에 **범위**(전체, 기간, 최근 N세션)와 **세션 단위 필터**(세션 유형, 장소, 컨디션, 큐 적용)를 적용한 세션 목록이다. 계산 규칙은 03과 같다(최근 N세션은 세션 단위 필터를 먼저 적용한 뒤 N개를 고른다).
- 메모 탭과 **같은 필터 상태**를 쓴다. 한쪽 탭에서 바꾸면 다른 탭에도 적용돼 있다.
- 차트의 가로축과 기간 표시가 이 목록을 쓴다.
- 조회 대상 세션은 메모가 1개 이상이므로, 1차 세션은 "1차 세션의 메모 전체"에서 구할 수 있다(6번).

### 2차: 메모 (통계 탭 전용)

- 1차 세션의 메모 전체에 **차트 태그**만 적용한다. 차트 태그가 `태그 전체`이면 거르지 않는다.
- 차트 태그는 하나다. 그 태그 **또는 그 자손**(모든 단계)이 붙은 메모를 고른다(03 태그 필터와 같은 규칙).
- **페이지의 평가 필터와 태그 필터는 통계 탭에 적용하지 않는다.** 평가는 차트가 보여주는 값이라 거르지 않는다.

## 3. 통계 탭 화면

위에서부터: 임시 안내(4번) / 기간 표시 / 세션별 평가 추이 카드 / 같이 달린 태그(3.3, 차트 태그를 골랐을 때) 또는 전체 메모에 달린 태그(3.4, `태그 전체`일 때). 탭 안의 내용 전체가 세로로 스크롤된다.

### 3.1 기간 표시

- 달력 아이콘 + `26/9/26 토 – 26/11/17 화`. 1차 세션 중 가장 오래된 세션 date – 가장 최신 세션 date, 짧은 형식(`formatters.dart`).
- 설정한 범위로 계산하지 않는다. "최근 1개월"이어도 실제 세션 날짜를 쓴다.
- 1차 세션이 하나면 날짜 하나만 쓴다.

### 3.2 세션별 평가 추이 카드

카드 맨 윗줄 왼쪽에 제목 `세션별 평가 추이`, 같은 줄 오른쪽 끝에 차트 태그 드롭다운. 그 아래로 차트 / 스크롤 안내 / 선택한 세션 줄.

**차트 태그 드롭다운**

- 제목과 같은 줄 오른쪽 끝의 알약 모양 버튼 하나. 라벨은 고른 태그면 `#포핸드`(primary 계열 채움, 굵게), 아니면 `태그 전체`(옅은 회색 채움, 테두리 없음). 오른쪽에 펼침 화살표. 버튼 앞뒤에 다른 글자는 두지 않는다.
- 누르면 버튼 아래에 메뉴가 버튼 오른쪽 끝에 맞춰 열린다. 항목:
  - 맨 위 `태그 전체`
  - 카테고리 머리글 `기술`, `상황`(누를 수 없는 작은 글자, 위에 구분선)과 그 카테고리의 태그. **기술·상황 카테고리만** 넣는다. 보관된(isArchived) 태그는 뺀다.
  - 태그는 `#이름`으로 쓴다. 순서는 03 태그 선택 시트와 같고, 자식 태그는 부모 바로 아래에 들여 쓴다.
  - 고른 항목은 배경색과 굵은 글씨로만 표시한다. 라디오 버튼, 체크 표시는 두지 않는다.
  - 메뉴가 길면 메뉴 안에서 세로로 스크롤한다.
- 항목을 누르면 바로 적용되고 메뉴가 닫힌다. 바깥을 누르면 바뀌지 않고 닫힌다.
- 기본값은 `태그 전체`. 고른 태그는 앱이 켜져 있는 동안 유지된다(탭 전환, 상위 조건 변경에도 유지). 앱을 다시 켜면 `태그 전체`.

**범례**

- 두지 않는다. 막대 색이 평가 아이콘 색과 같고, 바로 아래 선택한 세션 줄이 같은 색의 아이콘과 건수를 보여줘서 범례 역할을 한다.

**차트**

- 가로축: 1차 세션마다 열 하나. 왼쪽이 오래된 세션, 오른쪽이 최신 세션. 순서는 date → startMinutes → id 오름차순.
- 막대: 그 세션의 2차 메모를 평가별로 센 누적 막대. 아래에서부터 good, bad, ?, none. 칸 사이에 1dp 간격.
- 색: good·bad·?는 `evaluationColor`와 같다. none은 `onSurfaceVariant`를 연하게(불투명도 약 40%) 쓴다(막대에서만 연하게, 아이콘 색은 그대로). 막대 색 조정은 나중에 평가 아이콘 색을 바꿀 때 함께 한다.
- 2차 메모가 0건인 세션은 막대 대신 기준선 위에 작은 빈 원을 그린다. 열과 날짜 라벨은 그대로 둔다.
- 세로축: 최대값은 **1차 세션 전체** 중 가장 큰 세션 합계(화면에 보이는 열만이 아니다). 홀수면 1을 더해 짝수로 만들고, 최소 2. 눈금선과 라벨은 0, 최대값의 절반, 최대값.
- 날짜 라벨: `11/7`. 1차 세션이 두 해 이상에 걸치면 첫 열과 해가 바뀌는 열은 `27/1/3`처럼 연도를 붙인다.
- 열 너비는 터치 영역 48dp 기준의 상수로 둔다(약 400px 폭에서 7개 정도 보인다).

**좌우 스크롤**

- 열이 카드 폭을 넘으면 막대 영역만 좌우로 스크롤된다. 세로축 라벨과 눈금선은 고정이다.
- 처음에는 **오른쪽 끝**(최신 세션)이 보이는 위치다. 1차 세션 목록이 바뀌면(상위 조건 변경) 다시 오른쪽 끝으로 간다. 차트 태그만 바꾸면 스크롤 위치를 유지한다.
- 가려진 쪽 가장자리를 배경색으로 흐리게 하고 `‹` / `›` 아이콘을 둔다.
- 차트 아래에 좌우 화살표 아이콘 + `차트를 좌우로 밀어서 다른 세션을 볼 수 있어요`. 열이 한 화면에 다 들어가면 흐림 처리와 이 문구를 모두 숨긴다.

**세션 선택과 선택한 세션 줄**

- 열(막대 + 날짜 라벨)을 누르면 그 세션이 선택된다. 선택된 열은 배경을 옅게 칠하고 날짜 라벨을 굵게 한다.
- 처음에는 **최신 세션**이 선택돼 있다. 1차 세션 목록이 바뀌면 최신 세션으로 돌아간다. 차트 태그만 바꾸면 선택을 유지한다.
- 차트 아래 고정된 줄: 날짜(짧은 형식 `26/11/17 화`), 평가 네 가지의 아이콘 + 건수. **0인 평가도 표시한다.** 합계는 쓰지 않는다. 아이콘과 색은 `evaluationIcon`/`evaluationColor`.
- 줄 오른쪽 끝에 `세션 보기 ›` 글자 버튼. 누르면 그 세션의 세션 상세 시트를 고른 메모 없이 연다(3.5).

### 3.3 같이 달린 태그

차트 태그를 골랐을 때 차트 카드 아래에 보인다. `태그 전체`이면 이 자리에 3.4가 대신 나온다.

- 제목 `#포핸드 메모 19건에 같이 달린 태그`(19 = 2차 메모 수), 그 아래 작은 글씨 `칩을 누르면 두 태그가 함께 달린 메모를 시트로 보여줘요`.
- 대상: 2차 메모 전체(기간 전체). 그 메모들에 **직접** 붙은 confirmed 태그를 모은다. 부모 합산은 하지 않는다.
- **고른 차트 태그 자신은 뺀다.** 자손은 뺄 필요가 없다. 부모(`#발리`)를 고르면 `포발리`, `백발리`가 칩으로 나와 어느 쪽이 많은지 보인다.
- 카테고리별로 한 줄씩: 왼쪽에 카테고리 이름, 오른쪽에 칩(여러 줄로 감김). 줄 사이에 구분선. 카테고리 순서는 기술 / 폼 / 풋워크 / 상황 / 몸 / 컨디션이고 칩이 없는 카테고리는 뺀다. 모든 카테고리를 보여준다(차트 태그는 기술·상황만이지만 같이 달린 태그는 제한이 없다).
- 칩 내용은 메모 탭 요약 칩과 같다: `짧은공 5 · 👍1 👎4`(태그명, 메모 수, 평가별 아이콘과 건수, 0은 생략).
- 칩 순서: 카테고리 안에서 건수 많은 순, 같으면 이름 순.
- 같이 달린 태그가 하나도 없으면 `같이 달린 태그가 없어요.`
- 칩을 누르면 메모 시트가 열린다. 칩에 켜짐 상태는 없다(한 번에 하나만 열린다).

**메모 시트**

- 처음 높이는 화면의 약 70%, 위로 끌면 전체 높이까지 펼쳐진다. 아래 여백에 시스템 영역 높이를 더한다(03 세션 상세 시트와 같다).
- 제목(가운데, primary 색 굵은 글씨) `#포핸드  #짧은공`. 두 태그 사이에 `+` 같은 기호 없이 일정한 간격만 둔다. 그 아래 흐린 글씨로 `메모 5 · 26/9/26 – 26/11/17`(기간은 3.1 기간 표시와 같은 1차 세션 범위, 요일 없이).
- 2차 메모 중 그 칩의 태그가 직접 붙은 메모를 메모 카드로 늘어놓는다. 정렬은 03 메모 탭의 최신순과 같다(세션 date → startMinutes → id 내림차순, 같은 세션 안은 orderIndex 오름차순).
- 카드는 03 메모 탭 카드에서 오른쪽 화살표만 뺀 모양이다(3.6). **카드를 눌러도 아무 동작이 없다.**

### 3.4 전체 메모에 달린 태그

차트 태그가 `태그 전체`일 때 3.3 자리에 나온다. 3.3과 같은 칩·카테고리 줄 모양을 쓰고, 다른 점만 적는다.

- 제목: `전체 메모 61건에 달린 태그`(61 = 1차 세션의 메모 수).
- 그 아래 작은 글씨 `기술·폼·상황 태그만 보여줘요. 칩을 누르면 그 태그가 달린 메모를 시트로 보여줘요`.
- **카테고리는 기술 / 폼 / 상황 세 가지만** 보여준다(이 순서). 풋워크, 몸, 컨디션 태그는 세지도 보여주지도 않는다.
- 대상: 1차 세션의 메모 전체(기간 전체). 그 메모들에 **직접** 붙은 confirmed 태그를 센다. 부모 합산은 하지 않는다. 차트에서 선택한 세션과는 상관없다.
- 설명 글 아래 줄 오른쪽 끝에 정렬 메뉴 버튼(정렬 아이콘 + `많이 쓴 순` + 펼침 화살표). 누르면 버튼 오른쪽 끝에 맞춰 메뉴가 열리고, 항목은 `많이 쓴 순`(기본값) / `잘함 순` / `못함 순`. 고른 항목은 배경색과 굵은 글씨로 표시하고, 누르면 바로 적용되고 닫힌다.
- 정렬 규칙(카테고리 안에서):
  - 많이 쓴 순: 메모 수 많은 순 → 이름 순
  - 잘함 순: 잘함 수 많은 순 → 메모 수 많은 순 → 이름 순
  - 못함 순: 못함 수 많은 순 → 메모 수 많은 순 → 이름 순
  - 정렬은 순서만 바꾼다. 잘함·못함이 0인 칩도 그대로 보여준다.
- 대상 메모에 기술·폼·상황 태그가 하나도 없으면 `달린 태그가 없어요.`
- 정렬은 차트 태그처럼 앱이 켜져 있는 동안 유지된다.

**메모 시트(이 자리에서 열 때)**

- 3.3의 메모 시트와 같은 모양이다.
- 제목은 칩의 태그 하나 `#짧은공`, 부제는 `메모 8 · 26/9/26 – 26/11/17`.
- 1차 세션의 메모 중 그 태그가 직접 붙은 메모를 같은 정렬로 늘어놓는다.

### 3.5 세션 상세 시트 (03 수정)

03의 `showSessionDetailSheet`가 고른 메모 없이도 열리게 한다. 새 위젯을 만들지 않고 기존 시트를 고쳐 쓴다.

- 이유: 시트의 요소를 거의 그대로 쓰고, 다른 것은 메모 목록을 보여주는 방식뿐이다. 고쳐 쓰는 쪽이 코드 수정이 가장 적고 구조도 단순하다.
- 감수하는 점: 통계 쪽에만 필요한 기능이 늘면 한 위젯 안에 `memoId == null` 분기가 쌓일 수 있다. 아직 정해진 기능이 없으므로 미리 나누지 않고, **기능 추가가 확정될 때 분리한다.**
- `memoId`를 nullable로 바꾼다. 넘기면 03 동작 그대로다.
- `memoId`가 없으면: `선택한 메모` 라벨과 `같은 세션 다른 메모 N개 펼쳐보기` 버튼 없이, **모든 메모를 orderIndex 순으로** 펼쳐서 보여준다. 각 메모의 표시(본문, `#태그`, 평가 아이콘)는 03과 같다.
- `memoId`가 없으면 메모 목록 위에 `메모 N`(그 세션의 메모 수) 라벨을 둔다.
- 제목, 세션 요약(컨디션·마지막 식사, 큐, 스코어)은 바꾸지 않는다.
- 메모 탭에서 여는 시트의 동작이 바뀌지 않았는지 확인한다.

### 3.6 메모 카드 (03 수정)

- `MemoResultCard`에 오른쪽 화살표를 숨기는 옵션(기본값은 표시)을 더한다. 숨기면 카드를 눌러도 아무 동작이 없다.
- 메모 탭의 카드는 바뀌지 않는다.

### 3.7 갱신과 상태 유지

- 결과는 DB 변경을 따라 갱신된다(drift watch). 일지 탭에서 일지를 고치거나 지우고 돌아오면 반영돼 있어야 한다.
- 탭을 바꿔도 차트 태그, 선택한 세션, 스크롤 위치가 유지된다(03의 탭 상태 유지 규칙).

### 3.8 결과가 없을 때

1차 세션이 없으면 통계 탭 전체 대신 `조건에 맞는 세션이 없어요.` + **필터 초기화** 버튼(03 메모 탭 빈 상태의 버튼과 같은 동작).

## 4. 임시 안내 (필터 재구성 전까지)

- 페이지에 평가 필터나 태그 필터가 하나라도 걸려 있으면 통계 탭 맨 위(기간 표시 위)에 흐린 글씨로 한 줄: `평가·태그 필터는 통계에 적용되지 않아요`.
- 걸려 있지 않으면 숨긴다. 눌러도 아무 동작이 없다.
- 필터 재구성 명세에서 이 안내를 없앤다.

## 5. 데이터 계층

기존 계층 구조(CLAUDE.md "폴더 구조")를 따른다.

- **리포지토리 변경 없음.** 통계 탭은 `SearchRepository.watchMemos`에 **페이지 필터에서 평가·태그 조건만 비운 필터**를 넘겨 1차 세션의 메모 전체를 받는다. 1차 세션 목록은 그 메모들의 세션에서 구한다(조회 대상 세션은 메모가 1개 이상이라 빠지는 세션이 없다).
- **통계 집계는 UI와 분리한 순수 Dart**로 `lib/domain/search/`에 둔다. 입력: 1차 세션의 메모 목록, 태그 사전(`TagHierarchy`, 태그 이름·카테고리), 차트 태그 id(nullable). 출력:
  - 1차 세션 목록(정렬된 순서)과 세션별 평가 건수(0건 세션 포함)
  - 세로축 최대값
  - 기간 표시용 첫·마지막 세션 날짜
  - 같이 달린 태그: 카테고리별로 묶은 칩 항목(태그, 메모 수, 평가별 건수)
  - 칩 하나에 대한 메모 목록(정렬 포함)
  - 전체 메모에 달린 태그: 정렬(많이 쓴 / 잘함 / 못함)을 받아, 기술·폼·상황 카테고리별 칩 항목
- 날짜 라벨의 연도 표시 판단도 순수 함수로 두고 테스트한다.
- **화면 상태**: 차트 태그 id, 선택한 세션 id, 전체 메모에 달린 태그의 정렬을 freezed 모델 + Riverpod Notifier로 둔다(`lib/ui/search/`). 페이지 필터 상태(`searchProvider`)와는 따로 둔다.
- drift 생성 클래스는 `@riverpod` 반환 타입에 쓸 수 없다(CLAUDE.md). 03처럼 도메인 모델로 감싼다.
- 03에서 남겨 둔 `SearchAggregator.tagStats`와 `TagStatRow`, 그 테스트는 04에서 쓰지 않으므로 지운다.

## 7. 구현 단계

1. **통계 도메인**: 5번의 순수 Dart 집계와 6번 테스트 전부 통과. `tagStats` 정리.
2. **03 위젯 수정**: 세션 상세 시트의 고른 메모 없는 모드, 메모 카드의 화살표 숨김 옵션. 메모 탭에서 카드와 시트가 그대로 동작하는지 확인.
3. **통계 탭 – 차트 카드**: 기간 표시, 임시 안내, 차트 태그 드롭다운, 차트, 좌우 스크롤과 안내, 세션 선택과 선택한 세션 줄, 세션 상세 시트 연결, 빈 상태.
4. **통계 탭 – 태그 칩 영역**: 같이 달린 태그(3.3), 전체 메모에 달린 태그(3.4, 정렬 메뉴 포함), 메모 시트.
5. **점검**: 1번의 조회 1~4를 웹에서 실제 데이터로 해 보고, 탭 전환 후 상태 유지, 일지 수정 후 갱신, 좁은 폭(약 400px)을 확인한다. 세션이 1개, 7개 이하, 30개 이상일 때 차트를 각각 본다. 발견한 문제와 남은 한계를 정리해서 알려줄 것. 마지막으로 `CLAUDE.md`의 구현 현황과 향후 계획(필터 재구성, 요약 카드, 태그별 변화 목록)을 갱신한다.
